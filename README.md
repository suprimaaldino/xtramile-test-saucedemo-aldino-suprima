# SauceDemo Playwright Automation

E2E test automation for [SauceDemo](https://www.saucedemo.com) using Playwright + TypeScript, Page Object Model pattern, Allure reporting, and GitHub Actions CI/CD.

| Item | Detail |
|------|--------|
| Target Site | https://www.saucedemo.com |
| Framework | Playwright + TypeScript |
| Pattern | Page Object Model (POM) + Custom Fixtures |
| Reporting | Allure Report + GitHub Pages |
| CI/CD | GitHub Actions (2 parallel shards × 2 workers, Allure publish) |
| Auth Strategy | Playwright Storage State (login once, reuse across all tests) |
| Secrets | `.env` + Base64 encoding — passwords encoded, decoded at runtime |

## Quick Start

```bash
# 1. Clone
git clone https://github.com/suprimaaldino/xtramile-test-saucedemo-aldino-suprima.git
cd xtramile-test-saucedemo-aldino-suprima

# 2. Install dependencies
npm ci

# 3. Install Playwright browsers
npx playwright install

# 4. Setup environment
cp .env.example .env
# Edit .env and fill in the credentials (see Environment Variables section)

# 5. Run tests
npx playwright test
```

## Architecture

### Storage State (No Repeated Login)

Instead of logging in before every test, Playwright saves the browser session once and reuses it:

```
auth.setup.ts → login → save storage-state/{browser}.json
                              ↓
              chromium / firefox / webkit projects
              (all reuse saved session)
```

Each browser gets its own storage state file because cookies are browser-specific.

### Page Object Model (POM)

```
BasePage                    ← shared: allureStep(), slugify(), navigateTo()
  ├── LoginPage             ← login interactions
  ├── InventoryPage         ← product listing, sort, add-to-cart
  ├── CartPage              ← cart view, remove items
  ├── CheckoutStepOnePage   ← checkout info form
  ├── CheckoutStepTwoPage   ← order review + pricing
  ├── CheckoutCompletePage  ← confirmation page
  └── Header (component)    ← burger menu, cart icon, logout
```

Every page object extends `BasePage`. Test files never interact with locators directly — they call page object methods.

### Custom Fixtures

Instead of importing page objects manually, tests receive them via Playwright fixtures:

```typescript
import { test, expect } from '../src/fixtures/test-fixtures';

test('TC-01: login', async ({ loginPage, inventoryPage, page }) => {
  await loginPage.navigate();
  await loginPage.login('standard_user', 'secret_sauce');
  await expect(page).toHaveURL(/.*inventory\.html/);
});
```

All POM instances are auto-injected — no manual setup needed.

## Environment Variables

### How It Works

1. `.env` file (gitignored) contains credentials with Base64-encoded passwords
2. `src/helpers/env.ts` loads `.env` via `dotenv` and decodes passwords at runtime
3. In CI, GitHub Secrets inject env vars directly — no `.env` file needed

### `.env` File

```bash
# ── SauceDemo Users ──
SAUCE_STANDARD_USER=standard_user
SAUCE_STANDARD_PASS=c2VjcmV0X3NhdWNl           # base64 of "secret_sauce"

SAUCE_LOCKED_OUT_USER=locked_out_user
SAUCE_LOCKED_OUT_PASS=c2VjcmV0X3NhdWNl

SAUCE_INVALID_USER=standard_user
SAUCE_INVALID_PASS=d3JvbmdfcGFzc3dvcmQ=        # base64 of "wrong_password"

SAUCE_PROBLEM_USER=problem_user
SAUCE_PROBLEM_PASS=c2VjcmV0X3NhdWNl

# ── App Config ──
BASE_URL=https://www.saucedemo.com
```

### Encoding Passwords

```bash
# Linux/macOS
echo -n "secret_sauce" | base64        # → c2VjcmV0X3NhdWNl

# Windows PowerShell
[Convert]::ToBase64String([Text.Encoding]::UTF8.GetBytes("secret_sauce"))
```

`decodePassword()` auto-detects Base64 and decodes. Falls back to raw value if not encoded — so you can also use plaintext in `.env` for local dev.

### CI/CD (GitHub Secrets)

Add these secrets in **GitHub repo → Settings → Secrets and variables → Actions**:

| Secret Name | Value |
|-------------|-------|
| `SAUCE_STANDARD_USER` | `standard_user` |
| `SAUCE_STANDARD_PASS` | `secret_sauce` |
| `SAUCE_LOCKED_OUT_USER` | `locked_out_user` |
| `SAUCE_LOCKED_OUT_PASS` | `secret_sauce` |
| `SAUCE_INVALID_USER` | `standard_user` |
| `SAUCE_INVALID_PASS` | `wrong_password` |
| `SAUCE_PROBLEM_USER` | `problem_user` |
| `SAUCE_PROBLEM_PASS` | `secret_sauce` |

Values can be plaintext or Base64-encoded — both work.

## CI/CD Pipeline

### Test Execution (`.github/workflows/playwright-ci.yml`)

```
Push/PR to main
       ↓
  npm ci (install deps)
       ↓
  Run Playwright Tests (2 parallel shards × 2 workers = up to 4 concurrent)
       ↓
  Upload Allure artifacts (per shard)
```

```
                    GitHub Actions
                          │
                  ┌───────┴───────┐
                  │               │
               Shard 1         Shard 2
                  │               │
              2 workers        2 workers
                  │               │
                  └───────┬───────┘
                          │
               Up to 4 concurrent workers
                          │
                 ┌────────┼────────┐
                 ↓        ↓        ↓
             Chromium  Firefox   WebKit
```

- **Docker image:** `mcr.microsoft.com/playwright:v1.62.1-noble`
- **Shards:** 2 parallel jobs for faster execution
- **Workers:** 2 per shard (up to 4 concurrent across both shards)
- **Retries:** 2 retries in CI (0 locally)
- **Env vars:** Injected from GitHub Secrets

### Allure Report (`.github/workflows/allure-report.yml`)

```
Playwright Tests complete
       ↓
  Download Allure artifacts (shard 1 + shard 2)
       ↓
  Generate Allure HTML report
       ↓
  Deploy to GitHub Pages
```

```
Failure Artifacts (auto-captured per test):
   ↓
Screenshot → Trace → Video
   ↓
Allure Results (allure-results/)
   ↓
Merge shards → Generate HTML report
   ↓
GitHub Pages (public URL)
```

**Report URL:** `https://suprimaaldino.github.io/xtramile-test-saucedemo-aldino-suprima/`

### Setup Required

1. Go to **GitHub repo → Settings → Pages**
2. Set **Source** to **GitHub Actions**

## Allure Report

### Generate Locally

```bash
# Run tests first
npx playwright test

# Generate report
npx allure generate allure-results -o allure-report --clean

# Open report
npx allure open allure-report

# Or serve directly (auto-opens browser)
npx allure serve allure-results
```

### Report Features

- **Suites:** Tests organized by browser and module
- **Behaviors:** Tests mapped to TC IDs
- **Graphs:** Pass/fail trends, duration distribution
- **Timeline:** Parallel execution visualization
- **Attachments:** Screenshots, traces, and videos on failure

## Troubleshooting

| Issue | Cause | Solution |
|-------|-------|----------|
| `Missing required environment variables` | `.env` missing or secrets not set | Copy `.env.example` to `.env`, fill credentials |
| Firefox fails in CI | `$HOME` folder ownership in container | Ensure `HOME: /root` is set in workflow |
| Allure report empty (0 tests) | Artifact download fails | Check `run-id` and `github-token` in `allure-report.yml` |
| Tests timeout at login | Wrong credentials or site down | Verify credentials in `.env` and check https://www.saucedemo.com |
| `injected env (0) from .env` | `.env` is gitignored, not in CI | Normal — CI uses GitHub Secrets instead |
| Storage state not found | Auth setup didn't run | Run `npx playwright test --project=setup-chromium` first |
| Node 20 deprecation warning | GitHub Actions runner default | Harmless warning, workflow uses Node 24 |

## Adding New Tests

1. Create test file in appropriate `tests/` subfolder
2. Import fixtures from `src/fixtures/test-fixtures.ts`
3. Use page object methods — never interact with locators directly
4. Name test with TC prefix: `test('TC-XX: description', ...)`
5. Run locally: `npx playwright test tests/your-file.spec.ts`

### Example

```typescript
import { test, expect } from '../../src/fixtures/test-fixtures';

test('TC-XX: your test scenario', async ({ inventoryPage, cartPage }) => {
  // Arrange
  await inventoryPage.navigateTo('/inventory.html');
  await inventoryPage.addProductToCart('Sauce Labs Backpack');

  // Act
  await inventoryPage.navigateToCart();

  // Assert
  await cartPage.expectCartItemVisible('Sauce Labs Backpack');
  await cartPage.expectCartItemCount(1);
});
```
